# Для тебя ❤️ — обычный сайт, без сборки

Это ОБЫЧНЫЙ сайт: просто файлы HTML, CSS и JS. Никакого npm,
никакой сборки, никакого GitHub-терминала. Всё, что нужно —
блокнот и браузер.

## Файлы

- `index.html` — структура страницы (трогать не нужно)
- `style.css` — оформление (трогать не нужно)
- `app.js` — вся логика (трогать не нужно)
- `content.js` — **ВЕСЬ ТЕКСТ САЙТА**. Открой в любом текстовом
  редакторе, поменяй слова между кавычками, сохрани файл.
- `images/` — сюда класть фотографии
- `audio/` — сюда (необязательно) положить файл музыки

## Как проверить у себя на компьютере перед публикацией

Просто дважды кликни на `index.html` — он откроется в браузере,
и ты сразу увидишь, что получилось. Никаких серверов и команд
запускать не нужно.

## Как добавить фотографии

1. Переименуй свои фото в `photo1.jpg`, `photo2.jpg`, ..., `photo10.jpg`
   (или открой `content.js` и впиши свои собственные названия файлов
   в массив `MEMORIES` — там уже готовы 10 строк, просто замени
   значения `image`, `title`, `caption`, `date`).
2. Положи файлы в папку `images/`.
3. Можешь удалить файл `ПОЛОЖИ_ФОТО_СЮДА.txt` — он не нужен, просто
   подсказка.

## Как поменять текст

Открой `content.js` в блокноте (или в любом текстовом редакторе) —
там всё подписано комментариями на русском: заголовок, поздравление,
причины, текст письма, вопрос про день рождения и так далее. Меняй
только то, что находится МЕЖДУ КАВЫЧКАМИ `" "`, само расположение
кавычек и запятых не трогай. Сохранил файл — готово, пересобирать
ничего не надо.

## Как опубликовать (получить ссылку для Telegram)

Самый надёжный вариант — **GitHub Pages**. Он не зависит от зип-архивов
и капризных загрузчиков: просто перетаскиваешь файлы через сайт.

1. Зайди на **github.com** → зарегистрируйся (только почта, без карты).
2. Нажми зелёную кнопку **New** (создать репозиторий).
   Название любое, например `moy-podarok`. Поставь галочку **Public**.
   Нажми **Create repository**.
3. На странице репозитория нажми **Add file → Upload files**.
4. Перетащи ВСЕ файлы и папки этого архива (index.html, style.css,
   app.js, content.js, images, audio) прямо в окно браузера —
   всё сразу, одним перетаскиванием. Внизу нажми **Commit changes**.
5. Зайди в **Settings** (вкладка вверху репозитория) → слева **Pages**.
6. В разделе "Build and deployment" → **Branch** выбери `main` и
   папку `/ (root)` → нажми **Save**.
7. Подожди минуту, обнови страницу — вверху появится ссылка вида
   `https://твой-логин.github.io/moy-podarok/` — вот её и отправляй
   в Telegram.

Если позже захочешь поменять текст или добавить ещё фото — заходишь
в свой репозиторий на github.com, открываешь нужный файл, жмёшь на
значок карандаша (Edit), меняешь текст прямо в браузере и жмёшь
**Commit changes**. Сайт обновится сам за минуту, ничего скачивать
и заново заливать не нужно.
